# Contributing

1. Keep the pack free of personal names, absolute farm paths, live keys, and product lore.
2. Prefer placeholders: `[ADD_MODEL_HERE]`, `[ADD_PROVIDER]`, `[ADD COPYRIGHT HOLDER]`.
3. Run `python scripts/binder_smoke.py --dry-run` and `python scripts/run_failure_replay.py` before opening a PR.
4. Host adapters in scope: Codex CLI, Kilo, Grok Build, OpenCode. Claude Code is deferred.
5. Skills are advisory; CLI gates are enforceable. Do not claim otherwise.
